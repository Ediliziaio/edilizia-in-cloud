# Area dipendente deprecata

Le pagine storiche di `/dipendente` sono state spostate qui come riferimento e
rollback, senza essere piu' collegate al routing pubblico.

Il portale operativo per employee e subcontractor e' ora `/campo`, che copre le
funzionalita' mobile-first di timbratura, profilo, ferie, rapportini e lavoro in
cantiere.

Redirect mantenuti:

- `/dipendente` -> `/campo`
- `/dipendente/ore` -> `/campo/timbratura`
- `/dipendente/rapportini` -> `/campo`
- `/dipendente/profilo` -> `/campo/profilo`
- `/dipendente/ferie` -> `/campo/ferie`
