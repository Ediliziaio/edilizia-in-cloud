BUG #1 — Implementations.tsx: UUID hardcodato nel bulk update
------------------------------------------------------------------------
FILE: src/pages/admin/Implementations.tsx

PROBLEMA:
La mutazione bulkMutation usa questo pattern per "seleziona tutti":
  .neq('id', '00000000-0000-0000-0000-000000000000')
Questo è un hack non sicuro. Se in futuro esiste una company con quell'ID
(unlikely ma possibile), verrebbe esclusa. Inoltre confonde chi legge il codice.

FIX:
Sostituisci il bulk update con una query corretta senza filtro finto:

```typescript
// Prima (sbagliato):
const bulkMutation = useMutation({
  mutationFn: async (enable: boolean) => {
    const { error } = await supabase
      .from("companies")
      .update({ messaging_beta_enabled: enable })
      .neq('id', '00000000-0000-0000-0000-000000000000'); // ← RIMUOVI
    if (error) throw error;
  },
});

// Dopo (corretto):
const bulkMutation = useMutation({
  mutationFn: async (enable: boolean) => {
    // Aggiorna tutte le aziende (senza filtro = tutte le righe)
    const { error } = await supabase
      .from("companies")
      .update({ messaging_beta_enabled: enable })
      .gte('created_at', '2000-01-01'); // filtro sempre true, oppure usa .not('id', 'is', null)
    if (error) throw error;
  },
  onSuccess: () => {
    queryClient.invalidateQueries({ queryKey: ['impl-companies'] });
    toast.success(enable ? 'Modulo attivato per tutte le aziende' : 'Modulo disattivato per tutte le aziende');
  },
  onError: (err) => {
    toast.error('Errore durante l\'aggiornamento: ' + String(err));
  }
});
```

Alternativa più corretta: ottieni prima tutti gli ID con .select('id') poi fai
l'update in batch su quegli ID specifici.

DISCONNESSIONE #1 — Stripe non è collegato al cambio piano admin
------------------------------------------------------------------------
FILE: src/pages/admin/CompanyDetail.tsx + src/pages/admin/SubscriptionPlans.tsx

PROBLEMA:
- SubscriptionPlans.tsx ha campi stripe_product_id, stripe_price_id_monthly, yearly
- MA quando l'admin cambia piano a un'azienda (dialog "Cambia Piano" in CompanyDetail),
  cambia SOLO il DB (subscription_plan_id su companies), NON Stripe
- Risultato: l'azienda nel DB ha piano Premium ma Stripe continua a fatturare Basic

FIX — Crea Edge Function per cambio piano con sync Stripe:

```typescript
// supabase/functions/admin-change-plan/index.ts
import "jsr:@supabase/functions-js/edge-runtime.d.ts";
import { createClient } from "jsr:@supabase/supabase-js@2";
import Stripe from "npm:stripe@14";

const supabase = createClient(Deno.env.get("SUPABASE_URL")!, Deno.env.get("SUPABASE_SERVICE_ROLE_KEY")!);
const stripe = new Stripe(Deno.env.get("STRIPE_SECRET_KEY")!);

Deno.serve(async (req) => {
  const { company_id, new_plan_id, admin_user_id } = await req.json();

  // 1. Verifica l'admin è super_admin
  const { data: roleData } = await supabase
    .from("user_roles").select("role").eq("user_id", admin_user_id).single();
  if (roleData?.role !== "super_admin") {
    return Response.json({ error: "Unauthorized" }, { status: 403 });
  }

  // 2. Carica company e nuovo piano
  const { data: company } = await supabase
    .from("companies").select("stripe_customer_id, subscription_plan_id").eq("id", company_id).single();
  const { data: newPlan } = await supabase
    .from("subscription_plans").select("*").eq("id", new_plan_id).single();

  // 3. Aggiorna DB
  await supabase.from("companies").update({ subscription_plan_id: new_plan_id }).eq("id", company_id);

  // 4. Se Stripe è configurato, aggiorna subscription Stripe
  if (company?.stripe_customer_id && newPlan?.stripe_price_id_monthly) {
    const subscriptions = await stripe.subscriptions.list({
      customer: company.stripe_customer_id, status: "active", limit: 1
    });
    if (subscriptions.data.length > 0) {
      const sub = subscriptions.data[0];
      await stripe.subscriptions.update(sub.id, {
        items: [{ id: sub.items.data[0].id, price: newPlan.stripe_price_id_monthly }],
        proration_behavior: "create_prorations",
      });
    }
  }

  // 5. Audit log
  await supabase.from("admin_audit_log").insert({
    user_id: admin_user_id, action: "change_company_plan",
    target_type: "company", target_id: company_id,
    details: { new_plan_id, new_plan_name: newPlan?.name }
  });

  return Response.json({ success: true });
});
```

In CompanyDetail.tsx, chiama questa edge function invece di fare .update() diretto.

const handleExportCsv = async () => {
  // Carica TUTTI i log (non paginati) per l'export
  const { data } = await supabase
    .from("admin_audit_log")
    .select("action, target_type, target_id, details, created_at")
    .order("created_at", { ascending: false })
    .limit(1000);

  if (!data) return;

  const csvRows = [
    ["Data", "Azione", "Tipo Target", "ID Target", "Dettagli"],
    ...data.map(row => [
      new Date(row.created_at).toLocaleString("it-IT"),
      row.action,
      row.target_type || "",
      row.target_id || "",
      JSON.stringify(row.details || {}),
    ])
  ];

  const csvContent = csvRows.map(r => r.map(c => `"${c}"`).join(",")).join("\n");
  const blob = new Blob([csvContent], { type: "text/csv;charset=utf-8;" });
  const url = URL.createObjectURL(blob);
  const a = document.createElement("a"); a.href = url;
  a.download = `audit_log_${new Date().toISOString().split("T")[0]}.csv`;
  a.click();
  URL.revokeObjectURL(url);
};

// Nel JSX (accanto al titolo):
<Button variant="outline" size="sm" onClick={handleExportCsv}>
  <Download className="h-4 w-4 mr-2" />
