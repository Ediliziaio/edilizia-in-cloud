# Area 1 — Normativa Edilizia

## Cosa copre quest'area

Le regole con cui si fa l'impresa edile in Italia: sicurezza in cantiere, norme tecniche per le costruzioni, contratti collettivi del settore, titoli abilitativi urbanistici, contratti d'appalto, prezziari ufficiali. È la cornice giuridica e tecnica dentro la quale ogni decisione operativa va presa.

## Quando il Cervello pesca da quest'area

- L'utente parla di sicurezza, infortuni, POS, PIMUS, coordinatore.
- L'utente cita il "Decreto 81", "il TUS", "le NTC".
- L'utente chiede cosa serve per aprire un cantiere, fare una variante, gestire un subappalto.
- L'utente parla di contestazioni tecniche con la committenza o con la direzione lavori.
- L'utente fa domande sul livello degli operai, Cassa Edile, ferie e permessi (parte CCNL).
