# KPI finanziari — i numeri da guardare ogni mese

Un'impresa edile italiana media ha tra i 30 e i 100 KPI possibili. Sceglierne 12-15 e guardarli ogni mese basta. Tutto il resto è rumore o si deduce da questi.

Li raggruppo in 4 famiglie: **redditività, liquidità, indebitamento, efficienza**.

## Famiglia 1 — Redditività

Misurano quanto guadagna l'azienda rispetto a ciò che produce o investe.

**1. EBITDA Margin**
```
EBITDA / Valore della Produzione × 100
```
Range tipico costruzioni generali: 6-10%. Specializzate ben gestite: 10-18%.
Se sotto il 5%, il margine non basta a coprire ammortamenti, oneri finanziari, imposte → utile netto a rischio negativo.

**2. ROS — Return On Sales (Margine operativo)**
```
EBIT / Valore della Produzione × 100
```
EBIT = EBITDA − ammortamenti.
Range tipico: 4-8%. Considera l'usura dei mezzi.

**3. Margine commessa medio**
```
(Ricavi commessa − costi diretti commessa) / Ricavi commessa × 100
```
Range tipico: 12-22%. Sotto il 10% per più commesse = problema strutturale di pricing o di esecuzione.

**4. ROI — Return On Investment**
```
EBIT / Capitale investito netto × 100
```
Capitale investito = patrimonio netto + debiti finanziari netti.
Range tipico: 5-12%. Sotto il tasso bancario → l'azienda rende meno di quanto costa il debito.

## Famiglia 2 — Liquidità

Misurano la capacità di onorare le scadenze a breve.

**5. Current Ratio**
```
Attivo Circolante / Passivo Circolante
```
Sopra 1,2 = ok. Sotto 1 = l'azienda non può coprire i debiti a breve con gli attivi a breve.
In edilizia, attenzione: i lavori in corso gonfiano l'attivo circolante ma non sono liquidi nel breve.

**6. Quick Ratio (Acid test)**
```
(Attivo Circolante − Magazzino − Lavori in corso) / Passivo Circolante
```
Più severo. Sopra 0,8 = ok. Sotto 0,5 = tensione di liquidità.

**7. Posizione Finanziaria Netta (PFN)**
```
Debiti finanziari − Disponibilità liquide
```
È il **debito netto verso il sistema bancario**. La banca lo guarda di più del bilancio in senso stretto.

**8. PFN / EBITDA**
```
Posizione Finanziaria Netta / EBITDA
```
Sotto 3 = bassa leva. 3-5 = monitorare. Sopra 5 = il debito non è sostenibile dal flusso operativo.

**9. DSCR — Debt Service Coverage Ratio**
```
Flusso di cassa operativo / Servizio del debito (rate annue)
```
Sopra 1,3 = la cassa copre il debito con margine. Sotto 1 = l'azienda non ce la fa a pagare le rate solo con la cassa operativa.

## Famiglia 3 — Indebitamento

Misurano la solidità e l'autonomia patrimoniale.

**10. Indebitamento netto / Patrimonio Netto**
```
PFN / Patrimonio Netto
```
Sotto 1 = struttura sana. 1-2 = leva accettabile in fase di crescita. Sopra 2 = sotto-capitalizzato.

**11. Patrimonio Netto / Totale attivo**
```
Patrimonio Netto / Totale attivo × 100
```
Sopra il 25% = struttura solida. Sotto il 15% = sottocapitalizzazione. Sotto il 5% = quasi insolvenza patrimoniale.

**12. Oneri finanziari / Fatturato**
```
Oneri finanziari netti / Fatturato × 100
```
Sotto 1% = sano. 1-2% = attenzione. Sopra 2% = l'azienda paga troppi interessi rispetto a quanto produce.

## Famiglia 4 — Efficienza operativa

Misurano quanto bene l'azienda usa le sue risorse.

**13. Rotazione capitale circolante**
```
Fatturato / Capitale Circolante Netto
```
Più alto = capitale che gira più volte l'anno. Una rotazione bassa indica troppo capitale fermo in crediti/lic/magazzino.

**14. Costo del lavoro / Valore della Produzione**
```
Costo del personale / Valore della Produzione × 100
```
Range tipico: 25-40% in costruzioni generali. Differenze significative a seconda del livello di subappalto.

**15. Subappalti / Valore della Produzione**
```
Costi per servizi (subappalti) / Valore della Produzione × 100
```
Range: 20-50%. Imprese "integrate" sotto 25%, imprese "general contractor" sopra 40%.

## Cosa NON misurare

Ci sono numeri che sembrano interessanti ma non aggiungono nulla al decision making mensile:

- **Utile netto isolato**: è un risultato, non una causa. Già coperto da EBITDA + oneri + imposte.
- **Fatturato medio per dipendente**: in edilizia varia troppo per stagione e mix di subappalti.
- **Numero clienti**: dato anagrafico, non operativo.
- **Numero offerte emesse**: utile in CRM, non in finance.

## Frequenza di lettura

| KPI | Frequenza |
|---|---|
| EBITDA, margine commessa | Mensile |
| Current ratio, PFN, DSCR | Mensile |
| ROI, ROS | Trimestrale |
| Patrimonio Netto / Attivo | Annuale (post-bilancio) + simulazione semestrale |
| DSO/DPO | Settimanale (dashboard operativa) |

## Benchmark di settore — confronto con altri

Confrontare con altre imprese del settore è utile, ma serve attenzione:

- I bilanci pubblici (depositi camerali) sono spesso "magri" per ragioni fiscali.
- Le associazioni di categoria pubblicano studi periodici (ANCE, Confartigianato Costruzioni).
- Banche e advisor finanziari hanno benchmark proprietari.
- Software gestionali con dati aggregati (es. EiC con dati anonimizzati di una community di clienti) offrono benchmark realistici.

Confrontati per **dimensione e specializzazione**: un'impresa di costruzioni generali da 5M non si confronta con una specialistica di facciate da 5M.

## Da cosa partire — i 5 KPI di pronto soccorso

Se non hai mai monitorato KPI, comincia da questi 5:

1. **EBITDA margin** mensile
2. **Cassa attuale + previsione 60 giorni**
3. **DSO** medio
4. **PFN / EBITDA**
5. **Margine commessa medio** ultimi 6 mesi

In 30 minuti al mese hai un quadro che il 70% degli imprenditori edili italiani non ha. Solo questo ti porta avanti.

## Strumenti per gestirli

- Dashboard integrata nel gestionale (EiC ha widget dedicati per ogni KPI sopra).
- Excel/Google Sheets con macro: alternativa low-cost ma manutentiva.
- Power BI / Looker Studio: per imprese più strutturate, con un controller dedicato.

La regola: **un KPI che non è automatizzato non si guarda**. Se devi calcolare manualmente DSO ogni mese, dopo 3 mesi smetti. Automatizza l'estrazione.
