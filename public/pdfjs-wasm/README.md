# PDF.js image decoders

Assets copied from the installed pdfjs-dist 6.5.438 package (wasm/), retaining upstream licenses. Required by PDF.js 6 for CCITT/JBIG2 scanned delivery notes, JPEG2000 and color conversion. `src/lib/ddt/dividiPdf.ts` passes this directory as wasmUrl. Refresh these assets together with future pdfjs-dist upgrades. Do not remove the JS fallbacks or licenses.
